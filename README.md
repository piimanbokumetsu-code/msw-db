MSW患者管理 Ver.1.0.6（試験版）

変更点:
- 一般44床＋ICU23床の計67床を患者編集のベッド選択肢として固定。空床も常に選択可能。
- FileMaker患者CSV取り込み時のみICU3-7～15をICU3-1～9へ変換。取り込み前に確認ダイアログを表示。
- 既存の患者データはアプリ更新だけでは自動変更しない。既存患者は同じ患者IDでCSVを再取り込みすると更新される。
- 朝一印刷は67床の固定行に加え、未配置・不正番号・同じベッドに重複した患者も別ページに表示（対象がいる場合のみ）。
- iPad AirPrintの白紙問題は実機での再検証が必要。

重要:
- 既存アプリの削除・再インストール、Safariのキャッシュ削除は行わないこと。端末内の患者データを失うおそれがあります。
- CSV再取り込み前にバックアップを取得してください。実患者データをGitHubやチャットにアップロードしないでください。
- ICU3-7～9のCSV変換はFileMaker由来という前提。アプリ側で新規入力した患者には適用しません。


## Ver.1.0.7
設定 → データ移行の既存「患者CSVを読み込む」は追加・更新のまま維持。
新しい「患者CSVで全件入れ替え」は試験用患者データのみを置換します。患者ID（番号/ＩＤ/ID）・氏名・ベッド番号が必須です。IDの空欄・重複を検査し、ICU3旧番号を変換し、件数プレビューと二重確認後に暗号化データを保存します。薬剤・設定・マスター・暗証は保持します。
.xlsxは直接読めません。CSV UTF-8形式で保存してください。
